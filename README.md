A program that draws a newspaper front page summing up the world news of Sunday 22 November 2026 — COP31 ending with no deal, the 186-drone barrage over Ukraine, and Iran's radar claim meeting Bahrain's denial — plus 32 more verified stories, a world map, and a DATE CHECK box naming the events left out because they belong to other days. Drawn entirely in code with a hand-written bitmap font; no photos, no AI-generated pixels. Every claim carries a certainty tag (CONFIRMED / OFFICIAL / REPORTED / CLAIM).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
